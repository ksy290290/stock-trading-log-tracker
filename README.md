# 주식 매매일지 (Stock Trading Journal)

개인용 주식 매매일지 + 목표가/손절가 추적 + 성과분석 대시보드.
로컬에서 Streamlit으로 실행되는 웹앱이며, 매매 기록은 SQLite 파일(`stock_journal.db`)에 저장됩니다.

## 왜 이런 구조인가

토스증권은 개인 개발자용 공식 오픈API를 제공하지 않아서, 매매(체결) 내역을 자동으로
가져올 수 없습니다. 그래서 매수/매도는 **직접 입력**하고, 현재가만 외부 소스에서
자동으로 조회하는 구조로 만들었습니다.

- 국내 주식 현재가: 네이버 모바일 증권의 비공식 JSON API (`m.stock.naver.com`)
- 해외 주식 현재가: `yfinance` (Yahoo Finance)

두 소스 모두 비공식/무료 API라 조회가 가끔 실패할 수 있습니다. 이럴 땐 '목표가/손절가'
탭에서 현재가를 수동으로 입력할 수 있습니다.

## 설치 및 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 자동으로 열리며 `http://localhost:8501` 에서 대시보드를 볼 수 있습니다.

## 폰에서 접속하기 (같은 와이파이)

```bash
streamlit run app.py --server.address 0.0.0.0
```

PC의 로컬 IP(예: `192.168.0.5`)를 확인한 뒤, 같은 와이파이에 연결된 폰 브라우저에서
`http://192.168.0.5:8501` 로 접속하면 됩니다. 브라우저 메뉴에서 "홈 화면에 추가"를
하면 아이콘처럼 쓸 수 있습니다 (네이티브 앱은 아님).

외부(다른 와이파이/모바일 데이터)에서도 쓰고 싶다면 Streamlit Community Cloud 등에
배포해야 합니다 — 필요하면 추가로 설정 가능합니다.

## 기능

- **매매일지**: 종목, 매수/매도, 수량, 가격, 수수료, 날짜, 전략 태그, 매매 사유를 기록
- **목표가/손절가**: 종목별로 등록하고 현재가 대비 진행률 확인
- **노트**: 특정 매매와 무관한 시황/종목 분석 메모
- **성과분석**: 종목별 실현/평가 손익, 승률, 누적 실현손익 추이 그래프

## 한계 / 알려진 제약

- 평단가 계산은 **이동평균법**이며, FIFO 세무 기준과는 다를 수 있습니다.
- 보유기간 등 정밀한 로트별(lot) 분석은 지원하지 않습니다 (MVP 범위 밖).
- 시세 API가 비공식이라 사전 공지 없이 동작이 변경/중단될 수 있습니다.
